☁ גיבוי וסנכרון בענן – Firebase

משתמש ב-Firebase Realtime Database. כל מי שמזין את אותם פרטי חיבור רואה את אותם נתונים בזמן אמת. הנתונים נשמרים גם במכשיר, כך שאפשר לעבוד גם בלי רשת.

בחיבור ראשון: אם הענן ריק, הנתונים שבמכשיר יועלו. אם יש נתונים בשני המקומות, תישאל אם למזג. "העלאה" מחליפה את הענן, "הורדה" מחליפה את המכשיר.

איך מקימים את המסד
  1. ב-console.firebase.google.com יוצרים פרויקט, ואז Build ← Realtime Database ← Create Database.
  2. ב-Project settings ← General ← Your apps יוצרים אפליקציית Web ומעתיקים את apiKey.
  3. את Database URL מעתיקים ממסך ה-Realtime Database.
  4. בלשונית Rules מגדירים הרשאות. במצב בדיקה כל מי שיודע את הכתובת יכול לקרוא ולכתוב. להגבלה, מפעילים Authentication ← Anonymous ומגדירים: {"rules":{".read":"auth!=null",".write":"auth!=null"}}. אימות עובד רק כשהקובץ מוגש מכתובת https ולא נפתח ישירות מהדיסק.
